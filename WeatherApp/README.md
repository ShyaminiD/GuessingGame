# Weather App

This  is a Weather App where user can get live Weather information using city name.

## How it works

* Tkinter is used to build the graphical user interface(GUI).
* User enters a city name in the input field.
* The app sends a request to the OpenWeatherMap API.
* Weather details are fetched and displayed on the screen.

## Features
* Search weather using city name
* Displays:
    * Latitude and Longitude
    * Temperature
    * Weather Description
    * Max and Min Temperature
* Simple and beginner-friendly UI

## Technologies Used
* Python
* Tkinter
* Requests Library
* OpenWeatherMap API("https://openweathermap.org/api/current?collection=current_forecast)

## How to run

1. Make sure Python is installed on your system.
2. Run the file:


python main.py
