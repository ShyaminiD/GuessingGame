# Number Guessing Game

This is a simple Python program where the system generates a random number between 1 and 10, and the user tries to guess it.

## How it works

* The program generates a random number
* User enters a number between 1 and 10
* If the guess is correct → shows success message
* If not → shows incorrect message
* If input is invalid → shows error message

## How to run

1. Make sure Python is installed
2. Run the file:


python main.py
