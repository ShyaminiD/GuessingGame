# Madlibs Game

This is a simple game where user fills the  six prepositions to complete a short story

## How it works

* The program has a list prepositios from which the user has to choose. 
* User is prompted to enter a preposition. 
* if the entered preposition is in the list, it is accepted and added to userinputs 
* If not → shows a message and asks again.
* The user must enter a total of six valid prepositions.
* At the end, the story is printed using the user's inputs.

## How to run

1. Make sure Python is installed on your system.
2. Run the file:


python main.py
